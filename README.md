# MACro Pad

남는 아이폰을 Mac의 미디어 조작과 키보드 단축키 전용 패드로 바꿔 주는 무료 앱입니다.

**[⬇ Mac 앱 다운로드](https://github.com/blackjaguar43/macropad/releases/latest/download/MacroPadHost.dmg)** · [소개 페이지](https://blackjaguar43.github.io/macropad/) · [개인정보 처리방침](https://blackjaguar43.github.io/macropad/privacy-policy.html)

- macOS 14 Sonoma 이상, Apple 실리콘과 Intel Mac 지원, iOS 17 이상 아이폰
- Mac 앱은 Developer ID 서명 및 Apple 공증 완료

## 사용법

1. MacroPadHost.dmg를 열고 MacroPad Host를 응용 프로그램 폴더로 옮긴 뒤 실행합니다.
2. 아이폰 앱을 열고, Mac과 같은 Wi-Fi에서 Mac 메뉴 막대에 표시된 연결 코드를 입력합니다.
3. fn 단축키를 쓰려면 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 MacroPad Host를 켭니다.

재생 정보는 macOS의 비공개 기능으로 읽기 때문에, macOS 업데이트 후 일시적으로 동작하지 않을 수 있습니다.
