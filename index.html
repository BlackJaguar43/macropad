미디어 조작

Mac에서 재생 중인 미디어를 재생·일시 정지하고, 5초씩 앞뒤로 옮기고, 이전·다음으로 넘겨요. YouTube 쇼츠도 넘길 수 있어요.

지금 재생 중

제목, 아티스트, 앨범 아트와 재생 위치를 보여 주고, 막대를 끌어 원하는 곳으로 옮겨요.

Mac 볼륨

오른쪽 세로 막대로 Mac 전체 볼륨을 조절해요.

fn 버튼 5개

자주 쓰는 키보드 단축키나 Mac 앱을 버튼에 지정해 바로 누르거나 열어요. 누를 때 살짝 진동해요.

코드로 안전하게 연결

Mac 메뉴 막대의 8자리 코드를 입력한 아이폰만 연결되고, 통신은 암호화돼요. 코드는 직접 정할 수 있고, 여러 번 틀리면 잠시 막혀요.

계정과 광고 없음

같은 Wi-Fi 안에서만 통신해요. 계정, 광고, 데이터 수집이 없어요.

시작하기

1

Mac 앱 설치

내려받은 MacroPadHost.dmg를 열고, MacroPad Host를 응용 프로그램 폴더로 끌어다 놓은 뒤 실행하세요. 메뉴 막대에 아이콘이 나타나요.

2

아이폰 연결

아이폰 앱을 열고 Mac과 같은 Wi-Fi에서 로컬 네트워크 권한을 허용한 뒤, Mac 메뉴에 표시된 연결 코드를 입력하세요.

3

단축키 권한

fn 버튼을 쓰려면 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 MacroPad Host를 켜 주세요.

재생 정보는 macOS의 비공개 기능으로 읽기 때문에, macOS 업데이트 후 일시적으로 동작하지 않을 수 있어요.
